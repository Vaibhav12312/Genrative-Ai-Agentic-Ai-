# Day 15 – 45-Minute Final Test Checklist

## Suggested time allocation

| Time | Activity |
|---|---|
| 0–5 min | Read all instructions and identify required sections |
| 5–15 min | Review project architecture, data flow, and core features |
| 15–25 min | Review FAQ handling, duplicate cleanup, and fallback behavior |
| 25–35 min | Run/check tests and inspect important edge cases |
| 35–42 min | Review deployment, README, and known limitations |
| 42–45 min | Final review and submit |

## Final readiness checks

- [ ] Live URL opens successfully.
- [ ] Main page loads without visible errors.
- [ ] A verified general EPFO question returns an appropriate answer.
- [ ] An unsupported or account-specific question uses a safe fallback.
- [ ] No real personal account data is used in the demo.
- [ ] README explains setup, features, and limitations.
- [ ] Automated test result is current and accurately reported.
- [ ] One real failure and its measured fix are ready to explain.
- [ ] GitHub repository is accessible.

## Commands (run from the actual project directory)

Use the commands documented by your project. If it is a Python project with a configured virtual environment and pytest installed, a typical test command is:

```powershell
python -m pytest -q
```

Do not assume this command is sufficient if the repository README specifies additional checks.
